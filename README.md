## 🚀 Featured Projects

### Davids – .NET 10 Microservices & Zero-Trust Reference Platform

**My flagship project demonstrating modern .NET architecture, distributed systems and application security.**

A locally orchestrated microservices platform using Docker and .NET Aspire, designed to demonstrate secure identity, API gateway patterns, transactional messaging and automated security testing.

**Key engineering areas:**

- **Architecture:** Clean Architecture, domain-driven design and distributed microservices.
- **Identity:** OpenIddict, OAuth 2.1, OpenID Connect, RS256 and PKCE.
- **API Gateway:** YARP with Backend-for-Frontend (BFF) security patterns.
- **Messaging:** RabbitMQ, transactional Outbox/Inbox and distributed workflows.
- **Data:** SQL Server, Entity Framework Core and Redis.
- **Security:** CSRF protection, rate limiting, token revocation and refresh-token reuse detection.
- **Observability:** OpenTelemetry, Prometheus, Grafana, Jaeger and Seq.
- **Infrastructure:** Docker, .NET Aspire, Kubernetes and Istio configuration.

**Automated security engineering includes:**

- Static application security testing (SAST).
- Software Bill of Materials (SBOM) generation and verification.
- Container vulnerability scanning.
- API security and fuzz testing.
- Dynamic application security testing (DAST).
- Container signing and software supply-chain controls.
- Runtime security monitoring and policy enforcement.

**Repository:** [github.com/dav-Ste/Davids](https://github.com/dav-Ste/Davids)

## 🔐 Application Security & DevSecOps

I believe security should be integrated into the software development lifecycle rather than treated as a final release activity.

My projects incorporate automated security testing and supply-chain verification, including:

| Security capability | Tools |
|---|---|
| Static analysis | CodeQL, Semgrep |
| API security testing | Schemathesis, Microsoft RESTler |
| Dynamic testing | OWASP ZAP |
| SBOM generation | Syft |
| Vulnerability scanning | Grype, Trivy |
| Image signing | Cosign |
| Runtime security | Falco, Tetragon |

The objective is to identify vulnerabilities early, provide repeatable security checks and make security part of everyday engineering practices.
